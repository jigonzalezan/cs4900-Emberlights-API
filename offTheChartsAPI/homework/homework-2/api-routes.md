## Genre API Endpoints - Homework 5

The following Genre endpoints are implemented:

| Method | Endpoint | Description | Status |
|--------|----------|-------------|--------|
| GET | /genre | Get all genres | Implemented |
| GET | /genre/{id} | Get genre by ID | Implemented |
| GET | /genre/search?genreName=Rock | Search genres by name | Implemented |
| POST | /genre | Create a new genre | Implemented |
| PUT | /genre/{id} | Update an existing genre | Implemented |
| DELETE | /genre/{id} | Delete a genre by ID | Implemented |

Base URL: http://localhost:8080/off-the-charts

POST, PUT, and DELETE were tested successfully using Bruno.
